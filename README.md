# Spotify_music
Project Objective

The goal of this project is to:

Analyze relationships between audio features and popularity
Compare different music characteristics
Apply machine learning techniques
Generate visual insights using bar graphs
Produce publication-ready tables and figures

Research Questions

How does danceability affect track popularity?
Can we predict high popularity using audio features?
Do explicit songs differ in popularity from non-explicit songs?
How does genre influence popularity?
What are the average characteristics of tracks?
Does song duration affect popularity?
Can tracks be grouped using clustering techniques?
